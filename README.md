# 班級經營系統 — 家長端即時查核看板 (Parent Dashboard)

> **即時掌握孩子學習動態，親師攜手零距離。**  
> 由高雄市立七賢國中 107 王禹硯（國一生）自主研發設計，專為家長打造的直覺式即時作業繳交查核、聯絡簿查閱、108 課綱 21 門領域小考成績深度分析看板與 PWA 桌面化體驗。

---

## 📌 系統全景與設計理念

傳統家庭聯絡簿常有「孩子忘記帶回家」、「抄寫漏掉項目」或「作業缺交時家長無法即時得知」等痛點。  
**家長端即時查核看板**直接對接教師端雲端資料庫，家長只需透過手機或電腦瀏覽器，免下載安裝龐大 App，即可隨時查閱孩子的每日作業繳交進度與聯絡簿叮嚀。

---

## 🔑 核心功能亮點

### 1. 今日作業查核 — 🚀 免密碼直查（極致便利）
- **即時掌握繳交進度**：選擇孩子座號後，立即顯示今日作業完成百分比圓形圖與統整指標。
- **透明分類標籤**：作業清楚分為「✅ 已繳交」、「⚠️ 待訂正」、「❌ 未繳交」，點收狀態由導師在校即時更新。
- **各項作業詳細備註**：可直接查看各科作業繳交時間點、是否需要家長簽名、預估耗時與個別備註。
- **直達專屬連結支援**：支援網址直接帶入班級代碼與座號（如 `?code=777AAA&seat=12`），點擊直接進入孩子查核專頁，免除重複選擇座號之步驟。

### 2. 小考成績與學習分析 — 🔒 獨立專頁 ＋ 6 位數專屬 PIN 碼保護（嚴格防護）
- **隱私安全防護**：考量學生個人隱私與成績自主權，小考成績系統**獨立為專屬分頁**，需輸入由導師或學生端所提供之專屬 6 位數 PIN 碼（預設為 `100000 + 座號`，例如 12 號為 `100012`）方可解鎖。
- **開通先決機制**：必須等到導師在教師端後台為該學生設定開通 6 位數專屬 PIN 碼後，方可解鎖查閱成績。若尚未開通，系統會以清晰的說明引導家長向導師提出開通需求。
- **4 大關鍵 KPI 指標**：
  - 累計小考總數（含今日筆數）
  - 總體及格率 (%)
  - 全科平均表現與評級
  - 歷史最高分與強勢學科
- **SVG 學期成績進步趨勢圖**：
  - 動態貝茲曲線走勢圖，繪製歷次考試得分與班級均分基準線對比。
  - 智慧分析評語：自動判斷近期進步、穩定或需加強狀態。
- **臺灣 108 課綱 6 大領域 21 門學科深度表現分析**：
  - **語文領域（2 門）**：國語文、英語文
  - **數學領域（1 門）**：數學
  - **社會領域（4 門）**：歷史、地理、公民與社會、**綜合社會**
  - **自然科學領域（4 門）**：生物、理化、地球科學、**綜合自然**
  - **藝術與科技領域（5 門）**：音樂、視覺藝術、表演藝術、資訊科技、生活科技
  - **健體與綜合活動領域（5 門）**：健康教育、體育、家政、童軍、輔導
- **一鍵重新鎖定**：查閱完畢後，點擊「重新鎖定」按鈕即可立即關閉成績資訊，離開裝置時安全無虞。

### 3. 今日聯絡簿與生活札記
- **導師叮嚀與全班公告**：同步顯示教師發布的每日重要通知、明日應帶學用品與活動公告。
- **孩子心情日記互動**：同步看見孩子在學生端填寫的今日心情表情（如 😊 開心、💪 充實）與「給爸媽與老師的一句話」，促進親師生真誠互動。

### 4. 📲 Progressive Web App (PWA) 支援
- **一鍵安裝至桌面**：支援現代 PWA 標準，電腦瀏覽器或 Android 手機可於「設定」一鍵點擊「安裝至桌面/主畫面」。
- **iOS 專屬安裝引導**：針對 iPhone/iPad 提供專屬圖文指引彈窗，手把手教學「分享 -> 加入主畫面」，打造如原生 App 的日常查詢體驗。

### 5. 🛡️ 全站內自訂互動與問題回報
- **全站內自訂彈窗**：不論是提示訊息、密碼輸入或錯誤回報，全程採用網頁內部高質感 Modal，完全杜絕瀏覽器預設上方灰色彈窗。
- **意見反映與問題回報**：提供專屬 [Google 回饋表單](https://docs.google.com/forms/d/19BPzX6vMrSnvW3j2s4OOvaiP3p1gS8auGbRt3f9aFkM/edit)，方便家長隨時提供建議。

## ⚡ 極速載入架構 (Perceived Zero Latency)

為解決家長在通勤、行動網路 4G/5G 等弱網環境下頻繁查詢的需求，家長端採用**三階階梯式混合載入技術**：

1. **Step 1: 本地快取 (0ms 瞬開)**：立即從瀏覽器 LocalStorage 載入最近一次快取資料，打開網頁 0 毫秒即顯示上次查核畫面。
2. **Step 2: 輕量 REST API 探測 (~150ms)**：同時向雲端發送非阻塞輕量 HTTP 請求，快速比對版本時間戳。
3. **Step 3: Firestore onSnapshot 實時長連線**：若有新更新，背景建立長連線並平滑更新 UI，兼顧極速開啟與最新資料即時性。

- **框架**：純原生 Vanilla JavaScript (ES6+ Modules)
- **UI 與排版**：Tailwind CSS (響應式設計，完美適配 393×852 手機直向與電腦大螢幕)
- **圖示庫**：FontAwesome 6 Free/Pro
- **資料庫**：Google Firebase Cloud Firestore 9.x
- **PWA**：Web App Manifest + Service Worker 離線快取
